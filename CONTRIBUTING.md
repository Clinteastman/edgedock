# Contributing

Small, focused pull requests are welcome. Explain the problem, the change and
how you checked it. Open an issue before a major new integration.

- Keep the app usable on a shallow, wide touchscreen and a regular monitor.
- Keep browser content separate from native app privileges.
- Never commit real home addresses, dashboard URLs, cookies, tokens or profiles.
- Prefer Windows and .NET features to extra dependencies.
- Check full screen, keyboard focus, empty media state and unavailable web pages.
- State which Windows version, display scaling and media player you tested.

This is an independent community project, not an official Corsair product.
