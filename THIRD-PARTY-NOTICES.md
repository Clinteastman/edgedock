# Third-party notices

EdgeDock's Waveform widget includes views adapted from shaders whose authors chose
permissive licences. They were translated from GLSL to C# (ComputeSharp) and changed to
follow the music and EdgeDock's colour looks. The code is in
`src/EdgeDock/Controls/WaveformBorrowedShaders.cs`. All other Waveform views were written for
EdgeDock.

The licence lines below were read from the shader file headers in the xscreensaver project's
collection of ports (https://github.com/Zygo/xscreensaver/tree/master/hacks/glx/glsl).
